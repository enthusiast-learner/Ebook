A Java-based web application using Servlets, JSP, and MySQL to manage books online. It includes user and admin roles with CRUD operations for books, user authentication, and role-based dashboards.
**Features**
User Registration and Login
Admin Dashboard
Add / Edit / Delete Books
View books by category
Upload book images
Role-based access (Admin/User)
Profile management
MySQL database integration

.

🛠️ Tech Stack:-
Frontend: HTML, CSS, Bootstrap, JSP
Backend: Java Servlets, JDBC
Database: MySQL
IDE: Eclipse
Server: Apache Tomcat
Tools: VS Code, Postman (for testing), MySQL Workbench


🔐 Authentication:-
Role-based login system
Session tracking for security

📌 Future Enhancements:-
Add password hashing (bcrypt)
Pagination on book list
Add user reviews/ratings
Upload PDF/ebook file support
